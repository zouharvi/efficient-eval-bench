About the data

This snapshot compares … method entries across … synthetic scenarios. The base scenario contains 16 models and 500 evaluation items, with scores on a 0–1 scale. The scenarios vary model count, score scale, item- and model-dependent noise, automated metric reliability, and annotator behaviour.

The evaluation runner averages results over budgets from 10% to 100% of the full model–item matrix and across runs. Item-level Score Estimation measures score estimation error across all model–item pairs using Item MAE. Benchmark-level Score Estimation measures error in each model’s overall benchmark score using Benchmark MAE. Global Model Ranking measures pairwise ordering agreement between estimated and true model rankings using Kendall’s Tau. Top-Weighted Model Ranking measures ranking agreement using Weighted Kendall’s Tau, giving greater weight to agreement near the top of the leaderboard.

These are research results from the repository’s implementations on synthetic data. They should be read in the context of the scenario and evaluation objective, rather than as a universal ordering of methods.
